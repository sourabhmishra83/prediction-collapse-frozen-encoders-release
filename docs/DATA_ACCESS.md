# Data access

Source data are not redistributed. Obtain data under the source owners' terms:

- CoAID: https://github.com/cuilimeng/CoAID
- FakeNewsNet: https://github.com/KaiDMML/FakeNewsNet
- LIAR: https://www.cs.ucsb.edu/~william/data/liar_dataset.zip
- Monant official release: https://zenodo.org/records/5996864

The Monant dataset was obtained from its official source under citation and link-sharing conditions. Do not redistribute restricted source texts or expert annotations. Monant stance results evaluate claim/article stance, not whole-article truth. Dataset licenses and pretrained-model terms are independent of the MIT license for this code release. Hash-only input metadata can identify the original processed snapshots; hashes do not supply the omitted data or authorize redistribution. Exact preprocessing and private input requirements are documented in the included code.
