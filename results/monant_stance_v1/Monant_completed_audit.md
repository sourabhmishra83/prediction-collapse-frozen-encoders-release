# Completed Monant stance experiment audit

All 18 planned runs completed on Tesla T4 using CUDA. Independent local verification recomputed every initial/selected/final prediction metric for automatic validation and expert test, checked the earliest best post-update validation checkpoint, confirmed paired initialization, and verified all saved trajectory/prediction/checkpoint file hashes. Saved graph edges satisfy receive-only query orientation. All executed source hashes match the preserved prepared code. The frozen private input checksum and evaluation index were also checked against the preserved private dataset. No retraining was performed.

Expert test: 308 pairs (202 supporting, 86 contradicting, 20 neutral), shared across all runs. Unweighted selected collapse: 8/9; final collapse: 9/9. Weighted selected and final collapse: 0/9. All 18 initial expert evaluations collapse. Weighted selected macro-F1 mean (seed SD): text-only 0.4503 (0.0052), GCN 0.4346 (0.0125), GAT 0.4353 (0.0244). The training-majority constant baseline has macro-F1 0.2641 and accuracy 0.6558. Avoid equating majority accuracy with useful three-class discrimination.

Neutral recall remains low: selected weighted means are text-only 0.2167, GCN 0.2667 and GAT 0.1667, each assessed on only 20 neutral pairs. Recovery from prediction collapse therefore does not imply balanced class performance. The small observed graph/text differences do not establish an architecture ordering or equivalence. Three paired seeds are not independent expert-test samples. No significance or population-level precision claim is made.

Training uses automatic presence/stance labels. The 626-pair automatic validation set comes from smaller disconnected components; it differs in connectivity and supervision from expert testing. Test annotations were held out, including article/claim IDs and normalized text groups. This does not rule out semantic/source/time dependence. The experiment supports Monant as a fourth-source claim–article stance evaluation; it does not validate the prior binary article-truth derivative. Independent whole-article truth adjudication remains unperformed and is not required for this stated stance task.

Audit files: 101 output/provenance files retrieved. Selected model files and all endpoint prediction/trajectory files were hash-checked. The 94 MB frozen feature tensor was not downloaded or independently recomputed; its recorded metadata is retained. Restricted input/index/per-example annotation-derived files remain local or in the owner's Drive. The GitHub distribution contains code and aggregate metrics, without source article text or per-example expert labels.
